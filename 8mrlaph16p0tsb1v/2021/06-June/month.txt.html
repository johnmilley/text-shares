## Entries

### Work

Feeling not great about work lately. A steady decline in enthusiasm since the pandemic started, really. This Spring has been especially _bleh_. Assigned with doing work that I have close to 0 interest in, when I was initially led to believe that I would have ample time for my own development. 

Need to let these negative feelings go, do the work that I need to do as quickly and as good as possible, and then continue to work on myself, my interests, the things that make me the teacher that I enjoy being. Working on my own projects and telling the class about them goers a long way towards my own enjoyment in teaching. It gives me the necessary experience to feel confident in what I am doing.

### Systems and Pens

Let's figure this out. This iPad that I am typing on makes me happy. It is a fine little tool. It's a good tool to write on and to muse about things.

**Daily journal writing**: iPad using Drafts. I like my daily entry + brief notes system that I have set up within Drafts.
	- Action creates a daily template with date inserted.
	- Action to create brief notes that are time stamped. Primarily meant for iPhone entries.
	- Action that wraps up the day by appending any daily brief notes to the daily entry. Opens a dialog to save the entry in Dropbox. (Happy with my decision to go with dropbox, though that means that I may need to reconsider the monthly Apple One)

**Daily sketching + on the go notes**: Field Notes + Physical Journal (need to find my pen!)

**Any and all programming**: Windows machine using WSL. 
- At home I would like to set up a sit/stand desk that will allow me to plug in my Thinkpad and code away.
- Perhaps start incorporating Dropbox more in my workflow. Though Google Drive is working well for lecture notes, slides, assignments. I should test using Dropbox for code syncing across devices in the Fall. Github works too... ok stick with Github but ... get better at it.

In a mood, I am.
